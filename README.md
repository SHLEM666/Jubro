# Jubro

This application allows to use [JupyterLab](https://github.com/jupyterlab/jupyterlab) on Android smartphones more comfortably (compared to regular mobile browsers).

## How is it made

This project is based on Google's [NowInAndroid](https://github.com/android/nowinandroid) app, from which it has inherited the modular structure, MVVM architecture and build logic.
